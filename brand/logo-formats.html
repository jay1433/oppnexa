OppNexa · Logo Formats

Seven different formats

These are the real logo types — not variations of one idea. Each is a fundamentally different format, all built in the OppNexa brand (navy + blue, Plus Jakarta Sans). Pick the format you like; I’ll then perfect that one.

01WordmarkLogotype · text only

The company name as the logo — custom-styled type, no symbol. Clean, confident, zero ambiguity. Used by Google, Sony, Zoom.

02LettermarkMonogram · initials

The initials O + N as a compact monogram. Great where space is tight (app icon, favicon). Used by IBM, HP, HBO.

03Pictorial / Icon markRecognisable object

A literal symbol of what you do — a bid document, verified and ready. Instantly readable. Used by Apple, Twitter, Shell.

04Abstract markGeometric symbol

A symbol that isn’t a letter or object — here, a nexus: one hub linking many companies to many opportunities. Used by Nike, Adidas, Pepsi.

05Combination markIcon + wordmark

Symbol and name locked together — the most flexible format (icon alone for apps, full lockup for the site). Used by Slack, Spotify, Atlassian.

06Emblem / BadgeSeal · name inside a shape

Name and symbol fused inside a seal — authority and trust, ideal for a government-facing brand. Used by Starbucks, Harley-Davidson, universities.

07MascotCharacter

A character that represents the brand — here a watchful hawk, the sharp eye that spots every opportunity. Used by Twitch, Pringles, sports teams.

Note: mascots read as informal/consumer. For a B2B brand selling to software companies and government-facing clients, I’d steer you away from this one — included only so you see the full range.
